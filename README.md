# CIFAR-10 Image Recognition
My first deep learning project with PyTorch. The script trains a convolutional neural network to classify the CIFAR-10 dataset, periodically measuring validation accuracy. Once the model is trained, it is saved to a file for later use.

## Requirements

- Python 3
- PyTorch
- torchvision

Install the Python dependencies with:

```bash
pip install torch torchvision
```
